NATHALIA HIRATA BEAUTY - HTML PURO

Como usar:
1. Abra o arquivo index.html diretamente no navegador.
2. Para publicar no GitHub Pages, envie os arquivos index.html, styles.css e script.js para o repositório.
3. Não é necessário instalar Node.js, React, Vite ou executar comandos.

Arquivos:
- index.html: estrutura do site
- styles.css: visual e responsividade
- script.js: menu, filtros e modal dos serviços
